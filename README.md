### 💼 Featured projects
More details on my [portfolio](https://cristianomafrajunior.com.br/).

**Odoo ↔ Mautic integration** — Lead developer · Escodoo  
- Odoo module for bidirectional sync of Contacts and Companies with **Mautic** via REST API.
